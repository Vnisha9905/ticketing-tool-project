# Priority Levels

`P0` is reserved for escalations (see `escalation.md`) and is never assigned
by these criteria directly — it's only set when a ticket triggers escalation.

For all non-escalated tickets, assign one of:

| Priority | Criteria |
|---|---|
| **P1 (High)** | Blocks a paying customer's core workflow, but affects only that customer/account (not widespread). Time-sensitive but not an outage or legal/security matter. |
| **P2 (Medium)** | Real problem or request, but has a workaround or isn't blocking. Normal-priority bugs, billing disputes, most account/access issues. |
| **P3 (Low)** | No urgency — general questions, feature requests, cosmetic issues, documentation asks. |
