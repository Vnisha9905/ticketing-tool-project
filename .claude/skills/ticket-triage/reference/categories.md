# Categories

Pick exactly one category per ticket — the single best fit. If a ticket
touches an escalation trigger (see `escalation.md`), prefer `Outage` or
`Legal/Security` over any other category that also applies.

| Category | Recognize by |
|---|---|
| **Outage** | Service is down, unreachable, or broken for many/all users at once. Words like "down", "outage", "can't log in" (widespread), "500 error", "everything is broken". |
| **Legal/Security** | Data breach, unauthorized access, compliance/legal threats, privacy violations. Words like "breach", "hacked", "GDPR", "subpoena", "lawsuit", "leaked data", "PII exposed". |
| **Technical Issue** | A bug, error, or malfunction affecting one user or a specific feature — not a widespread outage. |
| **Billing** | Charges, invoices, refunds, payment methods, subscription cost questions. |
| **Account/Access** | Login problems, password resets, permissions, single-user access issues (not widespread). |
| **Feature Request** | Ticket asks for new functionality or a product change, not reporting something broken. |
| **General Inquiry** | Questions about how something works, documentation requests, anything that doesn't fit the above. |
